# Giumat

Demo di sito/menu digitale per Giumat, bar · focacceria a San Giovanni Gemini (Via Eremita 6).

Sito statico: solo `index.html`, nessuna build richiesta.

**Contenuti di esempio**: menu, prezzi e serate sono inventati per la proposta. Orari, telefono, indirizzo, Instagram e rating Google sono reali (fonti pubbliche, nov 2026).
Tutti i dati modificabili stanno in cima allo `<script>`: `MENU`, `EVENTS`, `OPEN`, `PHONE`.
